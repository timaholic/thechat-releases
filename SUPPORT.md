# Gainware Chat — Support

Gainware Chat is a voice-to-text intercom for live production crews: one device hosts a session, everyone on the same Wi-Fi joins, and speech becomes a shared live text feed — iPhone, iPad, Mac, Apple Watch, and any browser on the network.

## Quick start

1. **Host**: open the app → *Start a Server*. (A name is optional — you can set it later in Settings → Users.)
2. **Join**: on any other device on the same Wi-Fi, open the app and tap the session under *Join a session*.
3. **Talk**: turn the mic on and speak — your words post to the feed after a short pause. Or type in the composer.
4. **Watch from a browser**: Settings → Web shows a QR code any phone or laptop on the network can scan.

## Common questions

**Nobody sees my session / can't join.**
Both devices must be on the **same network**, and the host must still be running. Corporate/venue Wi-Fi with "client isolation" blocks device-to-device traffic — use a dedicated production network or a hotspot.

**Speech isn't posting.**
Check Settings → Audio: the right input and channel must be selected (on multi-channel interfaces, the wrong channel is the usual cause). The "Send after" slider controls how long a pause posts the sentence.

**Notifications aren't showing.**
Settings → Notifications in the app shows whether iOS/macOS has them allowed, with a shortcut to System Settings if not.

**Does audio leave my device?**
No. Transcription is on-device and only the text travels — and only over your local network. See the [privacy policy](PRIVACY.md).
